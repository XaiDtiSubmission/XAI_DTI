# Numerical objects and selectors

Use `payload/selectors/model_case_bindings.json` and `numerical_sidecar_bindings.json` after extracting the release assets. Those manifests bind every case, file hash and active archive member. Never bind a high-learning-rate head to another case's cache or original encoder.

* **Saved scores:** the C01 NPZ members are saved float32 prediction streams. Select `MODEL_GATE_old.npy` from each `h0_predictions.npz` and `MODEL_GATE_new.npy` from each `h1_high_lr_predictions.npz`. The original h0 archive also contains auxiliary historical low-head members; they are not the formal high-learning-rate h1 comparator. Role-specific `score_index0` in `saved_rows/role_order_manifest.json` and its indexed role files records the source order. Input hashes identify the encoded strings, not independent chemical or biological entities. `saved_rows/model_gate/frozen_labels.csv.gz` supplies exact GATE label values, with access/source conditions in DATA_SOURCES.md; AF18 supplies disposition and the payload supplies calibration. `scripts/verify_gate_saved_scores.py` reproduced 240 original/retained risk/gain entries from these staged objects, maximum absolute difference 0, without model inference.
* **Function responses:** complete-operation arrays are CPU float64 evaluations of transplanted frozen fusion heads. They are distinct from the saved F32 prediction object. `q = h1 - (a*h0+b)` uses the original case/endpoint affine slot; its projection is derived as `A_q=A_h1-a*A_h0`. `h1`, `q`, source-reference-specific `bar_qI` and an anchored risk contrast are separate objects.
* **Complete-operation layout:** [the original output schema](complete_operation/output_schema.json) specifies `operation_values.npy` shape `[322659,4,12]`, function order `[q,h0,h_aff,h1]`, columns `[A_D,A_P,A_DP,r_D,r_P,r_DP,epsilon_D,epsilon_P,epsilon_DP,I_src,signed_DP_identity_residual,signed_lower_bound_residual]`. The shared index shape is `[322659,14]` with columns `[source_GATE_index0,donor_FIT_index0,endpoint_code,A_key_id,B_key_id,C_key_id,D_key_id,A_cache_row,B_cache_row,C_cache_row,D_cache_row,main_weight_denominator,sensitive_weight_denominator,support_code]`. These are historical registered layouts, not shapes newly inferred by decoding the public arrays. Main-response arrays alone do not contain the separate fixed-permutation projection arrays or source-lower-bound arrays.
* **Path layout:** [original32_axes.json](original32_axes.json) states the original path axes. The saved original array is `[10,64,3,6,4,4]`: case, link, operation, span, function and `[A,r,epsilon,Skill]`; operations `[D,P,DP]`, spans `[1/32,1/16,1/8,1/4,1/2,1]`, functions `[q,h0,h_aff,h1]`. The core selects GINE case indices 5–9, D index 0, span index 5, and q/h1 indices 0/3. Cache shape `[56962,1024]` is F32; columns 0–255 are drug and 256–1023 protein. Fusion-head evaluation converts selected rows to F64. Role offsets are FIT `[0,46140)`, SELECT `[46140,51265)`, GATE `[51265,56962)`.
* **Weights:** complete `FIT_ROW_UNIFORM` averages eligible donor rows within a source; complete `FIT_PROTEIN_INPUT_UNIFORM` first assigns equal mass to retained protein-input keys, then equal mass to rows within each key. Restricted path weights renormalize the selected two donors. They do not replace either complete reference. Endpoint-specific and equal-endpoint summaries, source counts and link counts retain distinct denominators. In the core there are 16 sources and 32 links per endpoint, each source weight 1/16 and each donor weight 1/2; then five fits and Kd/Ki have fixed equal weights.
* **Errors:** `epsilon=r-A`; `E=mean(abs(epsilon))`, `B=mean(abs(r))`, `Skill=B-E`. The zero-response comparator has `E_zero=B`. Ratios use their original eligibility/null statuses and matching aggregation. A ratio of aggregate E and B is not the saved average of eligible raw ratios.
* **R02:** AF18 reports current retained support with frozen models/calibration. Complete O_SRC retains 206 Kd sources/8,150 links and 1,948 Ki sources/264,231 links. GATE retains 798 Kd/4,822 Ki groups. Original and follow-up path sources use their own retained-link normalization. Ranking retains tasks with all 32 original candidates eligible. Read the explicit `scenario`, reference, fit and endpoint columns; do not silently replace the original AF2–12 support with AF18 support.

The [historical numerical policy](complete_operation/numerical_policy.json) and [qualification records](../provenance/numerical_qualification/) preserve finite-value checks, algebra checks and empirical AD/FD criteria. They do not establish a certified floating-point error envelope, an interpolation safety radius or a new practical margin. No new confidence interval or p-value is produced by the release verifier.
